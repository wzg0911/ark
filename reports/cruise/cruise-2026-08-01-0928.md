## 2. 本轮核心发现：新建品牌页是「孤岛页」——曝光为 0

上一轮巡航（07:28 后）新建了 `docs/proof-of-state-trap.html`，定位为
「ARK 官方技术品牌阵地，持续更新的方法论主场」。本轮做入链审计时发现严重问题：

```
grep -rn "proof-of-state-trap" --include=*.html --include=*.md --include=*.js .
→ 零结果（除文件自身）
```

**页面本身线上可访问（HTTP 200），但全站没有任何一处链接指向它。**

这意味着：
- README 读者到不了
- 落地页 `index.html` 访客到不了
- blog 索引读者到不了
- 只有知道确切 URL 的人才能访问 → **实际曝光量恒为 0**

这是典型的「造好了但没接线」缺陷——**投入已发生，价值却完全未兑现**。
一个持续更新的方法论阵地，若无入口，等于不存在。

> 自我印证：这其实是 ARK 自己诊断的 Proof-of-State Trap 的同构变体——
> 「资产已存在」≠「资产可达」。存在性断言不等于可达性断言。
