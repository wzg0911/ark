### 1.3 专家方法论提炼

**华杉（华与华）- 超级符号理论**

**核心公式：**
```
品牌资产 = 超级符号 × 重复投资 × 时间积累
```

**应用要点：**
1. 找到品牌的"最小记忆单位"
2. 在所有触点重复这个符号
3. 持续投资，形成品牌资产

**复利飞轮基因：**
- 边际成本递减：符号一旦建立，后续使用成本趋近于零
- 积累效应：时间越长，品牌资产越厚
- 网络效应：用户认知度提升，传播成本降低

## 三、今日学习笔记

### 3.1 商业模型：超级符号理论

**核心洞察：**
品牌的本质不是"传播"，而是"投资"。每一次品牌曝光，都是在品牌资产账户里存钱。

**复利飞轮设计：**
```
超级符号设计 → 全触点重复 → 用户认知强化 → 传播成本降低 → 品牌资产增值 → 更多资源投入符号设计
```

**应用到项目评估：**
- 评估项目时，问自己：这个项目有没有"超级符号"潜力？
- 能否设计出一个最小记忆单位，让用户一眼记住？
- 能否在所有触点重复这个符号，形成积累效应？

### 3.2 方法论：精益创业

**核心公式：**
```
构建 → 测量 → 学习 → 再构建
```

**应用到MVP设计：**
1. **构建：** 最小闭环（1个引流帖 → 1个落地页 → 1个购买按钮）
2. **测量：** 转化率、客单价、复购率
3. **学习：** 数据反馈，调整产品/定价/渠道
4. **再构建：** 优化后的产品，扩大投放

**关键指标：**
- 激活率：用户完成首次付费的比例
- 留存率：30天后仍活跃的用户比例
- 推荐率：用户主动推荐的比例
