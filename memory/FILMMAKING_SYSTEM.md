## 第一章：好莱坞顶级编剧方法论

### 1.1 三幕结构（The Three-Act Structure）

```
第一幕（建立）25%
    ↓
钩子（前10秒抓住观众）
↓
世界建立（展示现状）
↓
触发事件（打破平衡）
    ↓
第二幕（对抗）50%
    ↓
主角面对挑战
↓
中点转折（一切改变）
↓
最低谷（绝望时刻）
    ↓
第三幕（解决）25%
    ↓
高潮（最终对决）
↓
解决（新平衡）
↓
余韵（情感落点）
```

### 1.2 英雄之旅（Hero's Journey）- 科幻片核心框架

```
普通世界 → 冒险召唤 → 拒绝召唤 → 遇见导师
    ↓
跨越门槛 → 考验/盟友/敌人 → 深入洞穴
    ↓
磨难 → 奖励 → 回归之路 → 复活 → 带着宝藏归来
```

**应用到元神AI：**
- 普通世界：人们的记忆散落在各平台，无法整合
- 冒险召唤：元神AI出现，可以拿回你的记忆
- 磨难：数据隐私、平台壁垒
- 奖励：完整的自我认知，数字主权
- 带着宝藏归来：让众生物质丰盈、精神富足、灵魂觉醒

### 1.3 情感共鸣五层次

```
第1层：感官冲击（视觉/听觉震撼）
第2层：情绪触发（恐惧/希望/好奇）
第3层：认知共鸣（"这说的就是我！"）
第4层：价值认同（"这和我的信念一致！"）
第5层：使命感召（"我要加入这个使命！"）
```

**目标：** 元神AI视频必须触达第4-5层

### 1.4 科幻片视觉语言

**镜头语言：**
| 镜头类型 | 情感效果 | 应用场景 |
|---------|---------|---------|
| 极远景 | 渺小感、宏大感 | 开场宇宙/城市俯瞰 |
| 特写 | 亲密感、紧张感 | 人物情绪、产品细节 |
| 低角度仰拍 | 力量感、崇高感 | 展示产品/品牌 |
| 高速慢动作 | 震撼感、史诗感 | 关键时刻 |
| 手持抖动 | 真实感、紧迫感 | 用户场景 |

**色彩语言：**
| 色调 | 情感 | 应用 |
|------|------|------|
| 冷蓝/青 | 科技感、未来感 | 技术展示 |
| 暖金/橙 | 温暖、人性 | 用户故事 |
| 深紫/黑 | 神秘、深度 | 品牌调性 |
| 白/银 | 纯净、可信 | 产品展示 |

## 第三章：元神AI视频制作计划

### 3.1 视频体系规划

**视频1：品牌宣传片（60秒）**
- 目标：让投资人在60秒内被震撼、被感动、被说服
- 风格：好莱坞科幻大片 + 情感共鸣
- 核心信息：元神AI是什么、解决什么问题、为什么是现在

**视频2：MVP产品演示（3分钟）**
- 目标：让普通人看懂产品功能
- 风格：清晰直观 + 真实场景
- 核心信息：如何使用、有什么价值、为什么要用

**视频3：路演融资视频（5分钟）**
- 目标：让投资人理解商业逻辑
- 风格：专业严谨 + 数据支撑
- 核心信息：市场机会、商业模式、团队能力、融资需求

**视频4：用户故事系列（每集90秒）**
- 目标：让目标用户产生共鸣
- 风格：真实温暖 + 情感共鸣
- 核心信息：用户痛点、使用场景、改变前后
