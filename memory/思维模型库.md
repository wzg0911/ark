## 一、商业评估模型

### 1.1 OO5F 橙海五层项目评估模型

**用途：** 全维度评估项目可行性，给出"启动/放弃/谨慎"建议

**结构：**

| Layer | 维度 | 核心问题 | 通过门槛 |
|-------|------|---------|---------|
| L1 需求层 | 真需求识别 | 是真痛点还是伪需求？ | ≥7.0分 |
| L2 市场层 | 橙海识别 | 是否有增长空间且竞争温和？ | ≥70分 |
| L3 模式层 | 三性评估 | 系统性入侵/平台掠夺/排他壁垒 | ≥70分 |
| L4 执行层 | 执行可行性 | 能否低成本验证？ | ≥70分 |
| L5 复利层 | 雪崩效应 | 是否有边际成本递减/网络效应？ | ≥60分 |

**评分细则：**

**L1 需求层（满分10分）**
| 维度 | 权重 | 10分标准 | 7分标准 | 4分标准 |
|------|------|---------|---------|---------|
| 场景 | 30% | 具体可描述 | 较清晰 | 模糊 |
| 人群 | 25% | 可识别可触达 | 可识别 | 较模糊 |
| 频率 | 25% | 每天多次 | 每天 | 每周 |
| 强度 | 20% | 生存威胁 | 严重困扰 | 明显痛点 |

**L2 市场层（满分100分）**
| 指标 | 权重 | 10分标准 |
|------|------|---------|
| 需求创新性 | 25% | 完全创新/中度创新/微创新 |
| 竞争温和度 | 25% | 无竞争/分散竞争/中等竞争 |
| 市场增长率 | 25% | ≥50%/≥30%/≥15% |
| 用户认知度 | 25% | 完全认知/大部分认知/部分认知 |

**L3 模式层（满分100分）**
| 评估维度 | 核心问题 |
|---------|---------|
| 系统性入侵性 | 模式能否快速渗透市场？ |
| 平台掠夺性 | 模式能否收割价值链？ |
| 排他性壁垒 | 模式能否阻止后来者？ |

**L4 执行层（满分100分）**
| 原则 | 检验问题 |
|------|---------|
| 先验证后投入 | 没验证前不花大钱吗？ |
| 能租不买 | 避免固定资产投入吗？ |
| 能外包不自建 | 非核心能力外包吗？ |
| 能自动不手动 | 尽早自动化吗？ |

**L5 复利层（满分100分）**
| 要素 | 权重 | 10分标准 |
|------|------|---------|
| 边际成本递减 | 25% | →0/显著递减/轻微递减 |
| 网络效应 | 25% | 强/中/轻微 |
| 积累效应 | 25% | 强/中/轻微 |
| 杠杆效应 | 25% | 强/中/低 |

### 1.2 飞轮效应模型

**用途：** 识别项目的复利机制

**结构：**
```
动力源（用户价值）→ 加速器（网络效应）→ 稳定器（护城河）
```

**经典案例：亚马逊飞轮**
```
更低价格 → 更多客户 → 更多卖家 → 更大销量 → 更低成本 → 更低价格
```

**应用要点：**
- 初始投入大，惯性让后续投入越来越小
- 产出越来越大
- 需要找到"第一推动力"

---

### 1.3 第一性原理

**用途：** 穿透表象，找到本质

**方法：**
1. 拆解问题到最基本事实
2. 从事实出发重新构建
3. 不依赖类比和经验

**应用场景：**
- 需求分析：用户的底层动机是什么？
- 模式设计：这个生意的本质是什么？
- 成本结构：哪些是必要成本，哪些是可以消除的？

## 二、决策思维模型

### 2.1 最优化决策框架

**来源：** 思维力三阶

**流程：**
1. 目标澄清：我们到底想达成什么？
2. 量化权衡：每个选项的收益/成本/风险是多少？
3. 风险对冲：最坏情况如何？能否承受？
4. 执行决策：选择并承担结果

**工具：决策矩阵**
| 选项 | 收益 | 成本 | 风险 | 净值 |
|------|------|------|------|------|
| A | | | | |
| B | | | | |
| C | | | | |

---

### 2.2 机会成本思维

**核心问题：** 选择A意味着放弃什么？

**应用：**
- 时间分配：做这件事，意味着不做什么事？
- 资源配置：投这个项目，意味着不投哪个项目？
- 每个选择都有代价，代价就是放弃的最优替代

---

### 2.3 沉没成本谬误

**核心认知：** 已经发生的成本与当前决策无关

**检验问题：**
- 如果我之前没有投入，现在会选择继续吗？
- 如果答案是否定的，就应该停止

---

## 三、认知思维模型

### 3.1 认知飞轮

**来源：** 思维力三阶

**结构：**
```
概念思考力（理解）→ 创新思考力（创造）→ 最优化决策力（行动）→ 反馈迭代
```

**关键洞察：**
- 飞轮一旦转动，成长从线性变为指数
- 需要持续"第一推动力"

---

### 3.2 结构化思维

**核心：** 从混乱中建立秩序

**方法：**
1. 金字塔原理：结论先行，以上统下
2. MECE原则：相互独立，完全穷尽
3. 分类归纳：找到事物的内在结构

**应用场景：**
- 信息整理：建立知识图谱
- 问题分析：拆解复杂问题
- 表达输出：清晰呈现观点

---

### 3.3 反思性思维

**核心：** 从经验中提取可迁移模型

**复盘模板：**
1. 目标是什么？
2. 实际结果如何？
3. 差距在哪里？
4. 根因是什么？
5. 下次如何改进？
6. 能提取什么模型？

---

### 3.4 生成性思维

**核心：** 从"解题者"进化为"出题人"

**方法：**
- 不满足给定框架内找答案
- 挑战问题本身："这是正确的问题吗？"
- 主动创造而非被动消费

---

## 四、复利系统模型

### 4.1 复利四要素

| 要素 | 定义 | 关键指标 |
|------|------|---------|
| 积累性 | 每次投入都沉淀为资产 | 资产增长率 |
| 可复用 | 同一资产多次变现 | 变现次数 |
| 可叠加 | 资产之间产生协同 | 协同效应 |
| 可自动化 | 减少人工依赖 | 自动化比例 |

---

### 4.2 边际成本递减模型

**核心：** 随着规模扩大，单位成本下降

**典型场景：**
- 软件产品：开发一次，无限复制
- 内容创作：创作一次，持续传播
- 品牌积累：投入一次，长期受益

---

### 4.3 网络效应模型

**核心：** 用户越多，价值越大

**类型：**
- 直接网络效应：电话、社交网络
- 间接网络效应：平台双边市场
- 数据网络效应：推荐算法越用越准

---

## 五、信息处理模型

### 5.1 信息金字塔

```
数据（原始素材）
  ↓ 整理
信息（有结构的数据）
  ↓ 分析
知识（可复用的信息）
  ↓ 提炼
智慧（可迁移的知识）
```

---

### 5.2 信息筛选原则

| 维度 | 标准 |
|------|------|
| 真实性 | 是否有可靠来源？ |
| 相关性 | 是否与当前任务相关？ |
| 时效性 | 是否已过时？ |
| 权威性 | 来源是否可信？ |

---

### 5.3 信息整合方法

1. **多源验证：** 至少3个独立来源
2. **交叉比对：** 发现矛盾点
3. **逻辑推演：** 用逻辑填补信息空白
4. **结构化输出：** 用框架组织信息

## 六、报告输出模型

### 6.1 金字塔原理

**结构：**
```
核心结论
├── 论点1
│   ├── 论据A
│   └── 论据B
├── 论点2
│   ├── 论据C
│   └── 论据D
└── 论点3
    └── 论据E
```

**原则：**
- 结论先行
- 以上统下
- 归类分组
- 逻辑递进

---

### 6.2 报告模板

**项目评估报告结构：**
1. 执行摘要（核心结论）
2. 项目概述
3. OO5F评估
   - L1 需求层评估
   - L2 市场层评估
   - L3 模式层评估
   - L4 执行层评估
   - L5 复利层评估
4. 综合评分与建议
5. 风险提示
6. 下一步行动
