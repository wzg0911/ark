## 推荐方案：OBS + 剪映 + 即梦

### Step 1：使用OBS录制屏幕（免费）

**安装OBS：**
```bash
# macOS
brew install obs

# 或访问 https://obsproject.com/download
```

**录制步骤：**
1. 打开OBS Studio
2. 点击"+"添加新场景
3. 添加"显示捕获"源（选择整个屏幕）
4. 点击"开始录制"
5. 演示应用功能（按照DEMO_GUIDE.md的脚本）
6. 点击"停止录制"
7. 视频保存在 ~/Videos/

**录制建议：**
- 分别录制4个视频（产品演示、技术讲解、用户场景、融资亮点）
- 每个视频录制时保持稳定的语速
- 可以多次录制，选择最好的版本

---

### Step 2：使用即梦生成AI配音（免费）

**访问即梦：** https://jimeng.jianying.com

**生成配音步骤：**
1. 注册账号
2. 上传视频或导入
3. 使用"AI配音"功能
4. 选择配音员风格（推荐"专业男声"或"温柔女声"）
5. 输入演讲稿
6. 生成配音
7. 导出视频

**演讲稿：**
已在DEMO_GUIDE.md中提供

---

### Step 3：使用剪映编辑视频（免费）

**安装剪映：** https://www.capcut.com

**编辑步骤：**
1. 打开剪映
2. 导入视频
3. 添加字幕
   - 使用"自动字幕"功能
   - 手动调整字幕内容
4. 添加特效
   - 转场效果
   - 滤镜效果
   - 贴纸和文字
5. 调整音量
   - 背景音乐（可选）
   - 配音音量
6. 导出视频
   - 分辨率：1080p
   - 格式：MP4

## 常见问题

### Q: 如何获得更好的音质？
A: 使用外接麦克风，或在安静的环境中录制。即梦的AI配音质量很高。

### Q: 如何添加背景音乐？
A: 使用剪映的"音乐"功能，选择免费音乐库中的背景音乐。

### Q: 如何生成中英双语字幕？
A: 先用剪映生成中文字幕，然后手动添加英文字幕。

### Q: 视频太大怎么办？
A: 使用剪映导出时选择较低的分辨率，或使用在线压缩工具。

### Q: 如何快速生成多个版本？
A: 录制一个完整版本，然后用剪映分割成多个短视频。
