### 健康检查
```bash

```

### 获取文档列表
```bash
curl http://localhost:8000/api/documents?limit=10
```

### 搜索文档
```bash
curl "http://localhost:8000/api/search?q=融资"
```

### 获取周回顾
```bash
curl http://localhost:8000/api/weekly-review
```

### 获取统计信息
```bash
curl http://localhost:8000/api/stats
```

### 连接飞书
```bash
curl -X POST http://localhost:8000/api/auth/feishu/authorize \
  -H "Content-Type: application/json" \
  -d '{"redirect_uri": "http://localhost:8000"}'
```
